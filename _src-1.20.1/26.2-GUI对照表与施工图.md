# 26.2 GUI 移植对照表（javap 实测，阶段 3 施工图）

## 一、渲染上下文（最关键 ✓ 名字完全变了）

| 1.20.1(Yarn) | 26.2 官方 |
|---|---|
| `net.minecraft.client.gui.DrawContext` | **`net.minecraft.client.gui.GuiGraphicsExtractor`** ✓ |
| `Net.minecraft.client.gui.GuiGraphics`（1.21 Mojmap 名） | 同上（26.2 里 `GuiGraphics` **不存在** ✗） |

渲染方法（`Screen` 实测 ✓）：
- ✗ 旧：`public void render(DrawContext ctx, int mouseX, int mouseY, float delta)`
- ✓ 新：`public void extractRenderState(GuiGraphicsExtractor g, int mouseX, int mouseY, float delta)`
- 需要 tooltip/字幕时用：`extractRenderStateWithTooltipAndSubtitles(GuiGraphicsExtractor, int, int, float)` ✓

## 三、Screen 生命周期与方法（实测 ✓）

```
protected void init()                        ✓ 还在
public final void init(int, int)             ✓ 存在（final，别覆盖）
protected void rebuildWidgets()              ✓（旧名 clearAndInit ✗）
protected void clearWidgets()                ✓（旧名 clearChildren ✗）
protected <T …> T addRenderableWidget(T)     ✓（旧名 addDrawableChild ✗）
protected <T extends Renderable> T addRenderableOnly(T) ✓
public boolean keyPressed(net.minecraft.client.input.KeyEvent)  ✓ ★签名变了：不再是一堆 int 参数
```

## 四、事件方法签名变化（要按新签名改 ✓）

- `keyPressed(KeyEvent)` ✓（不是 `keyPressed(int,int,int)` ✗）
- `mouseClicked(...)` / `mouseScrolled(...)`：属于 `ContainerEventHandler`，26.2 的参数也变了 ✗
  → 最省事的做法：**覆盖 `Screen#extractRenderState` 做绘制** ✓ 交互交给 `addRenderableWidget` 的控件（它们自己处理点击 ✓）
  → 我们原来的 `mouseClicked/mouseScrolled` 覆盖可以**直接删掉** ✓（那是为自绘交互写的 ✗ 新版控件自带 ✓）
