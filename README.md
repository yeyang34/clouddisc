> **歪歪网易云唱片mod——忠于原版，高于原版**
>
> 让 Minecraft 自己唱你的网易云：全程客户端，全图同步。中途进场也不掉拍。

**把被铁砧改过名的唱片放进唱片机，它就会播放网易云的歌；而且所有装了本 Mod 的玩家听到同一进度。**

## ⬇️ 下载

### 👉 [**点这里下载最新版**](https://github.com/yeyang34/clouddisc/releases/latest)

在 Releases 页面选 **`clouddisc-x.y.z.jar`**（**不要**下 `-sources.jar`）。

**更新时请先删掉 `mods/` 里的旧 jar 再放新的** —— 同时留两个同 id 的 jar 会让游戏拒绝启动。

## 🚀 一分钟上手

1. 装好 **Fabric 1.20.1** 与 **Fabric API**，把下载的 jar 放进 `.minecraft/mods/`
2. 进游戏，拿一张**普通唱片**，在**铁砧**上改成 `@歌曲id`
   - **歌曲 id 怎么找**：网易云点「分享 → 复制链接」，链接里 `id=` 后面那串数字就是
   - 例：`@188204`
   - 也可以加备注：`@188204（沉默是金）`、`@188204 张国荣`
3. 把改名后的唱片**放进唱片机** → 约 2 秒后开始播放
4. 屏幕下方会显示 **「歌名 - 歌手」**（联网查回来的真名），你的备注会跟在后面

> 那 2 秒是"统一开始刻"的预缓冲 —— 多人同步就靠它，属正常现象。

## 👥 多人一起听

| 情况 | 效果 |
|---|---|
| 都装了本 Mod | 自动同步：谁放歌，大家听到的是同一段（实测偏差约 50 ms，且不随时间增长） |
| 中途才进服 / 从远处走近 | 自动从**当前进度**接上，不会从头开始，也不会没声音 |
| 没装 Mod 的人 | 会听到原版唱片的声音（我们只能管到装了 Mod 的客户端） |

不需要服务器装任何东西。若服主愿意把**同一个 jar** 放进服务端 `mods/`，
跨公网同步会更省心（不装也完全能用，会自动降级）。

## ❓ 常见问题

| 现象 | 说明与解决 |
|---|---|
| **VIP / 独家歌放不了** | 本 Mod 默认只播放**匿名即可播放**的曲目。VIP 曲目需要「自备解析服务」，**不随本仓库提供**，见下方说明 |
| 日志里出现 `拿到的是 text/html` | 同上：该曲目不允许匿名播放（网易返回的是网页而不是音频） |
| 一点声音都没有 | 先看游戏里「唱片机 / 音符盒」**音量滑块是不是 0** |
| 想调音量、看教程、看更新日志 | 按 **`K`**（或输 `/clouddisc`）打开配置界面，里面有 4 节：播放 / 网络与音源 / **使用教程** / **更新日志** |
| 只想放本地文件 | 把 `ogg / wav / mp3` 放进 `游戏目录/clouddisc-music/`，唱片名写 `@local:文件名` |
| 缓存占地方 | 配置界面第 1 节可设「缓存上限 MB」（默认 512，超了自动删最久没听的） |

## 🔒 关于 VIP 曲目与本项目的边界

- 本 Mod **只播"匿名就能播"的内容**。
- VIP / 独家 / 下架曲目需要在**你自己的机器上用你自己的账号**自备一个解析服务
  （用你自己的登录换取播放地址，属个人自用范畴）。**本仓库不提供这类服务，也不推荐公开部署。**
- 本项目**不内置**任何第三方接口、共享 cookie，也**不解密** `.ncm` / `.uc` 等受保护格式。
  —— 除了法律风险，这类实现接口一变就废，也无法正常分发。

> 想放 VIP 歌，最稳当的做法是：把你**合法拥有**的音频文件放进 `clouddisc-music/`，
> 唱片名写 `@local:文件名` —— 这条路完全不碰任何服务器。

## 🛠 从源码构建（开发者）

```bash
./gradlew build          # 产物在 build/libs/clouddisc-x.y.z.jar
```

- Minecraft **1.20.1** / Fabric Loader / Yarn `1.20.1+build.10`
- JDK **17**、Gradle 8.8、Loom 1.6.12
- 纯客户端（`environment: client`，服务端组件可选且与客户端同一个 jar）

### 技术要点（为什么它"忠于原版"）

- **真替换声音**：注入 `SoundLoader#loadStreamed`，由 Minecraft 自己的 OpenAL 链路出声 ——
  距离衰减、"唱片机/音符盒"音量滑块、暂停、失焦静音全部沿用原版
- **同步模型照抄原版**：预取完成后广播统一开始刻，各端到点零延迟开声，全程不做周期性纠偏
- **中途加入**：主动询问"谁在放什么" → 用对方给的**内容位置**一次性对齐
  （原版此时是完全听不到的 —— 它的 1010 事件只发给插碟那刻 64 格内的玩家，且不会重发）

## 唱片机的物理声效（内置，不用装别的）

放歌时声音会**按真实空间关系**变化 —— 不是简单的音量大小，而是"听起来像从那个位置、穿过那些东西传过来"：

| 场景 | 你会听到 |
|---|---|
| 站在唱片机旁边 | 干净、明亮 ✓ |
| 隔着一堵**石头墙** | **明显发闷、变远**（高频被挡掉）✓ |
| 隔着一扇**关着的门** | 明显闷 ✓ |
| 把那扇门**打开** | **立刻变清晰** ✓（按"有没有真的挡住"判断，不看方块类型）✓ |
| 隔着**玻璃** | 只轻微闷 ✓ |
| 半砖 / 玻璃板 / 楼梯 / 栅栏 | 只有射线真的穿过实体部分才算挡住 ✓ |
| 潜进水里 | 明显闷、变小 ✓ |

**怎么调**：按 `K` → 第 2 节「物理声效」
· **强度**：`0` = 完全关闭（回到干净直通）／`1` = 默认／`2` = 最激进
· **隔墙闷度**：越大越闷（默认 4.5）
· **漏音通路数**：几条缝隙才算"透声"（默认 6，越大越严）

> 这是**本模组自己实现的**（用 OpenAL EFX 给我们的音源挂低通与混响发送 + 射线体素遍历），
> 和 **Sound Physics Remastered** 无关；两者同时装会互相叠加，建议只留一个 ✓
