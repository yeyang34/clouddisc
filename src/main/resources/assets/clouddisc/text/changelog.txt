CloudDisc 更新日志（简版）
想看技术细节请看 GitHub 上的 docs/CHANGELOG-内部.md

────────────────────────────────
0.7.0
────────────────────────────────
- 项目放到 GitHub 上管理：以后更新只要发个链接,
  不用再一个个传文件给朋友
- 更新日志分成两份: 这份是【简版】(给所有人看),
  另一份是【内部详细版】(每个修复的根因与实测数据)
- 播放与同步逻辑一行没改

────────────────────────────────
0.6.8
────────────────────────────────
- 磁盘: 缓存可以限制大小了(默认 512 MB, 超了自动删最久没听的)
- 文档: 写清了"用自己服务器放 VIP 歌"的完整做法

────────────────────────────────
0.6.7
────────────────────────────────
- 提示: 遇到 VIP 歌放不了时, 日志会直接告诉你有哪两条路可以走
- 文档: 教程里补上了怎么自己搭解析服务

────────────────────────────────
0.6.6
────────────────────────────────
- 修好: 进服时偶尔先响一下原版唱片、然后才切成网易云
  (现在直接就是网易云, 不会先响原版)
- 修好: 退出世界再进来偶尔接不上、完全没声音
  (现在会持续重试询问, 直到有人回答或有会话为止)

────────────────────────────────
0.6.3
────────────────────────────────
- 修好: 偶尔会同时听到原版音乐和网易云(两条音轨一起响)

────────────────────────────────
0.6.0 / 0.6.1
────────────────────────────────
- 新增: 屏幕下方显示的是【联网查回来的真名】(歌名 - 歌手),
  不再是一串 id。唱片名里只写 id 就够了, 你写的备注会跟在后
- 修好: 查歌名用的接口(原来的写法拿不到名字)

────────────────────────────────
0.5.0
────────────────────────────────
- 补回: 原版那种"正在播放: 歌名"的屏幕提示(之前被我们拦掉了)

────────────────────────────────
0.4.x
────────────────────────────────
- 新增: 【服务端可选组件】—— 服主把同一个 jar 放进服务端 mods/,
  跨公网同步就不用走聊天了(客户端不装也能用, 会自动降级)
- 修好: 聊天栏不再刷 [CloudDisc] 那种同步数据
  (有服务端中继或 UDP 直连时, 聊天通道自动静音)

────────────────────────────────
0.3.x
────────────────────────────────
- 新增: 配置界面(快捷键 K 或命令 /clouddisc), 里面还带
  【使用教程】和【更新日志】两页
- 简化: 唱片名直接写 @歌曲id 就行, 后面可以跟备注,
  例如 @186016(晴天)

────────────────────────────────
0.2.x
────────────────────────────────
- 新增: 中途进服、从远处走近的人, 会自动从【当前进度】接上
  (原版这种情况是完全听不到的)
- 修好: 中途加入定位错、定位服务偶尔卡住、双开时对方听到原版 等问题

────────────────────────────────
0.1.x
────────────────────────────────
- 第一个可用版本: 真正替换唱片机的声音(走 Minecraft 自己的音频引擎,
  距离衰减/音量滑块/暂停都沿用原版), 支持网易云链接与歌曲 id,
  支持 OGG / WAV / MP3
