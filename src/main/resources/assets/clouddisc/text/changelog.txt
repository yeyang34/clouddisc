CloudDisc 更新日志（简版）

格式约定：+ = 新增/改善，- = 修复/移除。技术细节见 GitHub 的 CHANGELOG.md 与内部文档。

────────────────────────────────
1.1.0（Minecraft 26.2）

+ 铁砧界面新增「☁ 网易云选歌」按钮：唱片放进铁砧 → 点按钮 → 游戏内搜歌 → 确认 → 名字自动填成 @<id> → 从铁砧拿取即完成
+ 选歌界面一次搜索同时返回【单曲 / 声音(播客单集) / 电台(整档)】：顶部胶囊只做本地筛选，切换不再发请求
+ 选歌界面细节：单曲右侧直接显示歌词；声音/电台显示节目与主播；类型标签固定列宽、选中行左侧主色条、底部实时显示「将写入：@id」
+ 唱片悬停显示网易云曲名与歌手（异步解析 + 缓存；没网只是不显示，不影响播放）
+ 解析服务新增 /search 路由，支持一次搜多种类型（type=1 单曲 / 2000 声音 / 1009 电台）
+ 物理声效：空气连通就不闷 —— 8 条偏移射线里 ≥3 条通透时遮挡压到 0.05（贴着唱片机放铁砧、或只砌一堵墙而上方透气，都不再判闷）
+ 物理声效：修好 Valve「房间/门道」模型 —— 之前泛洪深度只有 32 格、节点上限 2200，导致它从未生效；现在能真正算出「声音从墙上方绕过去」的路径
+ 混响发送加 0.35 上限（遮挡接近 0 时不会再反馈自激炸耳）
- 修复选歌后名字没填上：改名必须走原版 AnvilScreen.onNameChanged（只设置输入框不会通知服务端），且要等铁砧界面重建后再落地
- 修复铁砧按钮在没放唱片时也显示：现在与输入槽联动
- 修复铁砧 mixin 注入失败：26.2 的 addRenderableWidget 是泛型方法，@Shadow 解析不到，改用反射调用
+ 配置新增：anvilAssist（默认开）、physicsOpenAirRelax（默认开）、showDiscTooltip（默认开）

1.0.0（Minecraft 26.2 · 首个正式版）

+ 彩蛋「果冻唱片」：把唱片改名 @3438848556 放进去，20 格内的生物与玩家会跟着 130 BPM 卡点变成果冻；停止播放立即恢复
+ 循环相位纳入多人同步：后进玩家会落在与发起方相同的循环相位上
- 修复拔碟时整个游戏卡顿一下：关流与关管的 I/O 从渲染线程挪到后台线程
- 修复玩家不受彩蛋影响：26.2 里玩家走 AvatarRenderer，需要单独挂渲染注入点
+ 支持 Minecraft 26.2（Fabric），功能与 1.20.1 的 0.13.1 一致
+ 单曲循环：长按唱片留在唱片机里就会一遍遍播；循环在解码管线内部无缝衔接（不靠事件猜、不靠 seek）
+ 循环相位纳入多人同步：后进玩家会落在与发起方相同的循环相位上
+ 播客支持：网易云电台与单集现在也能点（解析服务侧已支持，唱片名照旧只写数字）
- 修复解除时长限制失效（长歌又被唱片时长截断）——改为在每刻把云唱片的播放计数归零
- 修复首尾各缺一点：环形缓冲 4 秒 → 12 秒，开播前预缓冲目标 2.5 秒
- 修复到结尾卡住/反复播最后一点：收尾时主动停止声音实例，不再依赖"流结束"
- 修复聊天兜底通道刷聊天栏：默认关闭（同步优先走服务器中继与 UDP）
+ 解除播放时长限制改为内置，不用再单独装 jukeboxlib
+ 物理声效算法与 0.13.1 逐位一致（日志实测复算确认）
+ 配置界面适配 26.2：文字、标签点击、窗口层级都正常
+ 装了 ModMenu 可直接从模组菜单打开配置
+ 播客（网易云电台 / 单集）也能点了，唱片名照旧只写数字
- 单曲循环暂时关闭（配置默认 false）
- 26.2 版暂不含自定义音效包以外的额外内容

0.13.0

+ 物理声效换成「房间 + 门道」模型：柱子、箱子、台阶、半砖不再影响声音
+ 门开着声音从门里传出来（闷一档）；门关着明显闷
+ 站在唱片机正上方的屋顶上也能挡声
+ 木头 / 楼梯 / 半砖屋顶都能挡声
+ 玻璃更闷（与木板同级），绕房子走不再忽闷忽亮
+ 变化更顺滑：变闷约 1 秒、变清楚约 1 秒、余响约 0.5 秒
+ 开阔地带与洞穴余响更饱满
+ 配置界面：标签栏、卡片、小窗口不再重叠
- 树叶按实测吸声调低
- 贴墙放唱片机时旁边那堵墙不再被忽略
- 站在高处听正下方不再被误判为被挡住
