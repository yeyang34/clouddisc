歪歪网易云唱片mod——忠于原版，高于原版
让 Minecraft 自己唱你的网易云：全程客户端，全图同步
铁砧一改名，网易云就上门；中途进场，从不掉拍。

CloudDisc 云唱片 · 使用教程

────────────────────────────────
一句话
────────────────────────────────
把任意唱片在铁砧上改个名, 它就能在唱片机里播放网易云的歌,
而且所有装了这个 mod 的玩家听到的进度是一致的。

────────────────────────────────
第一步: 找到歌曲 id
────────────────────────────────
在网易云里点「分享 - 复制链接」, 会得到类似:

  分享XX的单曲《晴天》: https://music.163.com/song?id=186016

其中 id= 后面那串数字(186016)就是歌曲 id。
也可以直接把链接粘到唱片名里, mod 会自动识别。

────────────────────────────────
第二步: 铁砧改名
────────────────────────────────
右键铁砧 - 放一张唱片 - 在名字框里输入:

  @186016

然后从输出格取出改名后的唱片。
后面可以随便加备注(备注会被忽略), 例如:

  @186016(晴天)
  @186016 周杰伦 2003
  @186016-我实测能播的那首

只认开头那串数字, 所以备注里再出现数字也没关系。
屏幕下方"正在播放"显示的是【联网查回来的真名】(歌名 - 歌手),
例如 @1330348068 会显示"起风了 - 冯沁苑(买辣椒也用券)"。
如果你还写了备注, 会拼在真名后面: 起风了 - ...(我挑的)。
所以唱片名里【只写 id 就够了】, 不用自己抄歌名;
查不到真名时会退回你写的备注, 都没有就显示"网易云 #id"。

────────────────────────────────
第三步: 放进唱片机
────────────────────────────────
右键唱片机把唱片放进去, 约 2 秒后开始播放。
那 2 秒是"统一开始刻"的预缓冲, 多人同步需要它, 属正常现象。

────────────────────────────────
什么歌能放
────────────────────────────────
免费 / 非独家的歌可以放。
VIP / 独家 / 下架 / 地区受限的歌放不了 —— 网易会返回一个 404 网页,
日志里会明确写「拿到的是 text/html…不是音频文件」, 这不是 bug。
想放 VIP 歌只能靠你自己的解析服务(见下面「进阶」)。

────────────────────────────────
多人同步
────────────────────────────────
- 装了同一个 mod 的人会自动同步: 谁放歌, 大家听到的是同一段。
- 中途才进服、或者从远处走过来的人, 会自动从"当前进度"接上,
  既不会从头开始, 也不会没声音。
- 没装 mod 的人会听到原版唱片的声音(我们只能管到装了 mod 的客户端)。

────────────────────────────────
音量与听感
────────────────────────────────
- 游戏里「唱片机 / 音符盒」音量滑块照常生效(走的是原版音量体系)。
- 声音定位在唱片机上: 走远会变轻, 超出衰减范围就听不到。
- 本 mod 还有两个旋钮:
    总音量   整体响度(1.0 = 原样, 4.0 约等于原版唱片)
    输出余量 给峰值留多少余量, 越小越不容易削顶(有爆音就调小)

────────────────────────────────
进阶: 本地文件 / VIP 歌
────────────────────────────────
- 本地文件(最干净, 什么歌都能放):
  把 ogg / wav / mp3 放进游戏目录的 clouddisc-music/,
  唱片名写 @local:文件名(不带扩展名)。
  这条路径完全不碰网易服务器, 所以 VIP 歌也一样能放
  —— 前提是你自己合法拥有那个音频文件。
- VIP 歌(用你自己的账号权限):
  在你自己机器/服务器上跑一个小服务, 用【你自己的】账号登录,
  调用网易官方接口换取该曲目的可播放地址, 然后返回给 mod。两种返回都行:
    · JSON:  {"title":"歌名 - 歌手", "url":"http://.../x.mp3"}
    · 或直接返回音频字节流(此时这个地址本身就被当成音频地址)
  然后在配置里把「自建解析服务」填成:
    http://你的地址/?id={id}   或   http://192.168.2.13:8080/song/{id}
  要点:
    · 权限来自你的账号 → 你能听的歌它就能给出地址 → VIP 可放
    · cookie 只存在你的服务里: 本 mod 不保存、不打印、也不同步你的凭据
    · 别把这个服务裸露在公网(它等于拿着你的账号): 绑局域网/VPN, 或加个 token
    · 拿到的是普通音频地址, 同伴也能直接下载, 所以"只有发起方要配音源"依然成立
- 本 mod 不做的事(请理解):
  不内置任何第三方接口或共享 cookie, 不解密 .ncm/.uc 等受保护格式,
  也不提供"免费 VIP"那类做法。除了法律风险, 这类实现接口一变就废,
  也无法在 Modrinth/CurseForge 正常分发。

────────────────────────────────
进阶: 用一台自己的服务器专门解析 VIP 歌
────────────────────────────────
这台服务器和"我的世界服务器是谁的"完全无关 —— mod 只是去请求你配置的
那个 HTTP 地址, MC 服主不需要知道、也不用装任何东西。合理分工是:

  你的解析服务器   只用你的账号换地址; **不落盘**(纯内存即可, 可选几分钟的缓存)
  每个玩家的机器   负责下载与缓存(游戏目录/config/clouddisc/cache),
                   体积可以用配置里的「缓存上限 MB」限制(默认 512, 0=不限)

你的服务器两种返回模式, 选一种实现:

  A) 返回地址(先试这种, 最省流量):
     {"title":"歌名 - 歌手", "url":"http://.../x.mp3"}
     玩家直接从 CDN 下载 → 你的服务器几乎不耗带宽
  B) 直接返回音频字节流:
     玩家经过你的服务器拉流 → 不落盘, 但耗你的上行带宽
     若网易给的 VIP 地址绑定了请求方 IP(玩家直连会 403/404), 就必须用这种

安全(必须做, 因为它等于拿着你的账号):
  · 加一个长随机 token: 可以写进 URL, 也可以用 mod 的 httpHeaders 配置成请求头
  · 别裸露公网: 绑 VPN/内网, 或只放行朋友的 IP 并限速
  · 服务器日志里不要打印 cookie

维护成本(说实话):
  · 你的账号 cookie 会过期, 需要偶尔更新
  · 建议只和朋友自用, 不要做成公开服务(平台条款与法律风险由你承担)

────────────────────────────────
网络
────────────────────────────────
- 同一局域网内自动发现, 默认不用配置。
- 若网络屏蔽了组播 / 广播, 可以在配置里手写对端地址(udpPeers)。
- 还留了一条"聊天兜底通道": UDP 不通时用聊天消息传同步数据。
  代价是没装 mod 的人会在聊天栏看到 [CloudDisc]... 这样的行,
  可以在配置里关掉它。
- 最省事的一条: 让服主把本 mod 的同一个 jar 放进服务端的 mods/ 目录。
  服务端组件只做"原样转发字节", 不解析内容, 所以以后客户端怎么升级
  它都不用跟着改。装了之后跨公网也能同步, 而且不再刷聊天。
  没装也完全没影响 —— 客户端会自动降级。
- 提醒: 跨公网时"同一局域网自动发现"是无效的(你在自己家、朋友在他家),
  这时要么靠服务端中继组件, 要么和朋友连同一个 VPN。

────────────────────────────────
怎么打开这个界面
────────────────────────────────
- 快捷键 K (可在 选项 - 控制 - 云唱片 里改)
- 命令 /clouddisc
- 装了 ModMenu 的话: 模组列表里点 CloudDisc 的设置按钮

────────────────────────────────
出问题怎么查
────────────────────────────────
日志文件: 游戏目录 /logs/latest.log, 搜 CloudDisc。
常见几行:

  解析失败 …            歌曲 id 写错了, 或该歌不可匿名播放
  拿到的是 text/html    这首是 VIP / 独家, 放不了 → 看上面「进阶」的两条路
  起播位置离谱          定位算错(请把这行发给作者)
  seek … 未生效         解码跟不上(把预缓冲调大些)
  一点声音都没有        先看「唱片机 / 音符盒」音量是不是 0

────────────────────────────────
已知限制
────────────────────────────────
- 只支持 OGG / WAV(16-bit) / MP3 三种格式
- 跨公网还不能自动同步(同一局域网可以)
- 起播有约 2 秒延迟
- 能播多久受"那张原版唱片的时长"限制(放长曲请用 music_disc_blocks)
- 鹦鹉还不会跳舞(挂点取舍; 屏幕下方的"正在播放"曲名已在 0.5.0 还原)
